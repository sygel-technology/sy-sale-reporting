It also adds the botanic denomination to the sale report.

Usage
=====

To use this module, you need to:

1. Go to Sales / Configuration / Botanic Denominations. Create your
   botanic demomination records
2. Go to Sales / Products. Open a produc's form view. Fill the "Botanic
   Denomination" field
3. Go to Sales / Orders. Sell a product with botanic denomination. Go to
   Sales / Reporting / Sales, you can filter and group the sales by
   botanic denomination
